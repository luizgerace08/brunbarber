# Brun Barber Elegance

Preciso de um site para uma barbearia localizada no endereço : Rua Ciro Monteiro, 174
O horário das 9:00 ás 18:00 de terça á sabado;
com a paleta de cor preta e dourada, um site que mostra elegância e sutileza, minimalista porém bem programado, o site deve ter funções de agendamento e direcionamento para o whatsapp, o valor do corte é 25 reais e a sobrancelha é 10, tem apenas um barbeiro que é o dono, chamado Gustavo Brun, e o nome da barbearia é BRUN BARBER
